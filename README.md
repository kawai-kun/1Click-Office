# 1Click Office 3.0 Enterprise

Bộ công cụ Add-in hỗ trợ soạn thảo văn bản và xử lý bảng tính chuyên nghiệp dành cho **Microsoft Word** và **Microsoft Excel**.

## 🚀 Tính năng nổi bật

### 1. Microsoft Word (1Click.dotm)
- **Chuẩn hóa thể thức văn bản:** Tuân thủ 100% Nghị định số 30/2020/NĐ-CP của Chính phủ về công tác văn thư.
- **Đánh số trang linh hoạt:**
  - *Chuẩn Nghị định 30:* Đánh số giữa đầu trang, tự động ẩn trang đầu.
  - *Đánh số từ trang bất kỳ:* Cho phép tùy chọn số trang bắt đầu, số thứ tự bắt đầu, vị trí trên/dưới.
- **Xử lý nhanh:** Tự động căn lề chuẩn (trên 20-25mm, dưới 20-25mm, trái 30-35mm, phải 15-20mm), giãn dòng chuẩn, xóa dòng trống thừa, sửa bảng biểu.
- **Giao diện:** Tiếng Việt có dấu 100%, hệ thống icon trực quan, thông báo hiển thị tiếng Việt Unicode sắc nét.

### 2. Microsoft Excel (1Click_Excel.xlam)
- **Đọc số thành chữ:** Đọc tiền tệ tiếng Việt chuẩn xác (Hàm =DOCSO(), =VND(), =USD()...).
- **Tiện ích bảng tính:** Tách/ghép họ tên, xóa dòng trống, định dạng kế toán, căn lề và chuẩn hóa nhanh.
- **In ấn một chạm:** Căn chỉnh vừa khít trang in tự động.

### 3. Tự động Cập nhật Online
- Tích hợp nút **"Kiểm tra cập nhật"** trên thanh Ribbon Word và Excel.
- Tự động nhận diện bản cập nhật mới nhất từ GitHub và nâng cấp trong 3 giây.

## 📦 Cài đặt
1. Tải file **1Click_Setup.exe** hoặc giải nén **BoCaiDat_1Click_v3.0.zip**.
2. Chạy file cài đặt 1Click_Setup.exe và làm theo hướng dẫn.
3. Mở Microsoft Word hoặc Microsoft Excel để trải nghiệm ngay.
